**Pas de nouveau site ici : reprendre un site existant, trouver ce qui ne va pas, et le corriger.**

## Le projet

La Panthère est une agence de web design lyonnaise dont le site était mal référencé, lent et peu accessible. La mission : **auditer le site, puis l'optimiser** en matière de référencement, de performance et d'accessibilité.

## Ce que j'ai corrigé

- **Référencement** : balise `title` et méta-description réécrites, structure des titres remise dans l'ordre, langue de la page déclarée, et retrait de listes de liens vers des annuaires, une technique de référencement abusive dite « black hat » ;
- **Performance** : images allégées et redimensionnées, CSS et JavaScript minifiés, scripts chargés en fin de page, polices chargées plus efficacement, bibliothèques hébergées avec le site plutôt que sur un CDN ;
- **Accessibilité** : textes alternatifs des images réécrits, libellés ARIA sur les liens des réseaux sociaux, contrastes corrigés (dont du texte blanc sur fond blanc), balises sémantiques ;
- validation du code HTML et CSS avec les outils du W3C.
