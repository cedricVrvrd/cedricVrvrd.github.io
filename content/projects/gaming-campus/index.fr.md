**Un exercice d'entraînement : reproduire une page d'accueil en HTML et CSS.**

## L'exercice

Le but était de reproduire la page d'accueil d'une école de jeux vidéo, pour s'entraîner à la mise en page : barre de navigation, bandeau d'en-tête, sections d'icônes et blocs de contenu.

## Ce que j'ai pratiqué

- la mise en page avec **Flexbox** et **CSS Grid** ;
- l'adaptation aux différentes tailles d'écran avec les media queries ;
- les transitions CSS au survol.

## Technologies

HTML · CSS · Flexbox · Grid · responsive design
