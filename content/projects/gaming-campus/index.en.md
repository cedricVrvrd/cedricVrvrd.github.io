**A practice exercise: recreate a home page in HTML and CSS.**

## The exercise

The goal was to recreate the home page of a video game school, to practise layout: navigation bar, header banner, icon sections and content blocks.

## What I practised

- layout with **Flexbox** and **CSS Grid**;
- adapting to different screen sizes with media queries;
- CSS hover transitions.

## Tech stack

HTML · CSS · Flexbox · Grid · responsive design
