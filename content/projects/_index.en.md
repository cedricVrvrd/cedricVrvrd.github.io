Before systems and networks, I followed the **OpenClassrooms Web Developer path** (2022–2023), which led to the French **Web Developer and Integrator professional qualification (RNCP level 5, EQF level 5)**. Each project started from the brief of a fictional company: build a page from a mock-up, optimise an existing site, code a dynamic interface, build a secure API.

The projects are listed from the most complete to the simplest. The last two are small practice exercises from the same period.

Every demo is live on GitHub Pages except **Piquante**: it's an API, so it needs a server and a database to run. Its code is available on GitHub.

These projects are a few years old. I'm showing them as they are, as the first steps of my path.
