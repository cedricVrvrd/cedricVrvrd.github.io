**A mock-up built mobile first, with pure CSS animations and no JavaScript.**

## The brief

Ohmyfood lets you book a gourmet restaurant's menu in advance. The job: **build the mock-up** of the home page and four restaurant pages, mobile first, then for larger screens.

## What I built

- a **mobile-first** build, then adapted for tablets and desktops;
- CSS organised with **Sass**: colour variables, separate files per component and per page;
- **CSS animations**, no JavaScript: loading screen, dishes appearing one by one, hover effects on buttons and cards;
- code validated with the W3C tools.

## Tech stack

HTML · CSS · Sass · CSS animations (keyframes) · responsive design
