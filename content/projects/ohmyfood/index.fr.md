**Une maquette intégrée en partant du mobile, avec des animations en CSS pur, sans JavaScript.**

## Le projet

Ohmyfood permet de réserver à l'avance le menu d'un restaurant gastronomique. La mission : **intégrer la maquette** de la page d'accueil et des quatre pages de restaurants, d'abord pour mobile, puis pour les écrans plus larges.

## Ce que j'ai réalisé

- une intégration **mobile first**, adaptée ensuite aux tablettes et aux ordinateurs ;
- un code CSS organisé avec **Sass** : variables pour les couleurs, fichiers séparés par composant et par page ;
- des **animations en CSS**, sans JavaScript : écran de chargement, apparition progressive des plats, effets au survol des boutons et des cartes ;
- la validation du code avec les outils du W3C.

## Technologies

HTML · CSS · Sass · animations CSS (keyframes) · responsive design
