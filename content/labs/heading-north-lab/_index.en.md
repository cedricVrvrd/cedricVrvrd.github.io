**Heading North Lab** is a long-running project on my Proxmox server. It grows with my Bachelor's in DevOps Systems Administration: every new skill is applied to the same infrastructure.

## The scenario

**Norrøn Voyages** is a 15-person travel agency running small-group treks in Iceland, the Faroe Islands and Norway. Its IT grew without a plan: one server doing everything, a flat network, shared passwords, and a WordPress site edited directly in production.

Last spring, the site was defaced through an outdated plugin and stayed offline for several days. Now the agency's main Norwegian partner, bound by NIS2, requires security guarantees from its suppliers.

My role: the DevOps sysadmin hired to rebuild the infrastructure, automate it, then defend it.

> Norrøn Voyages is a fictional company, created as the scenario for this lab.
